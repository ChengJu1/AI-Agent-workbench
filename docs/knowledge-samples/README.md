# 知识库示例文档与模板

这里提供 4 份已填写的虚构业务文档和 1 份通用模板，供本项目的知识库上传、分段和检索演示使用。所有组织、产品和业务规则均为示例，不代表真实制度或本项目已实现的功能。

## 上传与检索

1. 在工作台“知识库”中新建“演示知识库”。
2. 点击“上传文档”，同时选择 `documents` 目录中的 4 份 Markdown 文件。
3. 检查每份文件是否显示已入库，再点击“预览分段”查看来源章节及行号。
4. 使用下面的词条进行检索，并核对返回原文。当前为关键词检索，宽泛的自然语言问题可能匹配不到预期内容。

| 文件 | 建议检索词 | 应重点核对的原文 |
| --- | --- | --- |
| [资源申请制度](./documents/01-资源申请制度.md) | `GPU`、`8 小时`、`临时存储` | 单张且不超过 8 小时由项目负责人审批；两张及以上或超过 8 小时共同审批；存储默认 100 GB、14 天 |
| [工时填报规范](./documents/02-工时填报规范.md) | `填报截止时间`、`0.5`、`更正申请` | 周五 18:00 前提交；最小单位 0.5 小时；已通过记录按更正流程修改 |
| [产品说明与常见问题](./documents/03-产品说明与常见问题.md) | `邀请链接`、`72`、`待审核` | 邀请链接有效期 72 小时；提交成功后进入待审核 |
| [值班排障操作手册](./documents/04-值班排障操作手册.md) | `KB-UPLOAD-01`、`KB-SEARCH-02`、`MCP-CONNECT-03` | 各编号对应的检查步骤和反馈信息 |

可用 `GPUZXQ987654` 测试无匹配结果。查询会按词条匹配和排序，不保证固定的第一名或每次只返回一份文档；应核对结果中的原文和来源。

不要把本说明文件一并上传，否则说明中的测试词和答案也会参与检索，干扰结果判断。

## 版本更新与隔离测试

- 去重：原文件再次上传，应提示内容未变化，版本保持不变。
- 更新：复制第一份文档到其他目录，保留文件名，把存储额度 `100 GB` 改为 `120 GB` 后上传。应显示版本更新，检索 `临时存储` 并确认额度已变化；跨库文档不应随之更新。
- 隔离：建立第二个知识库，只上传工时文档；在第二个库检索 `GPU` 应没有结果。
- 多片段：示例正文包含多个章节，可观察自动切分和相邻片段重叠。片段数以页面实际结果为准。

## 编写自己的文档

复制 [知识文档通用模板](./templates/知识文档通用模板.md)，替换占位内容后上传。保留明确标题、完整规则、业务编号和适用范围，有助于定位和核对原文。模板本身无需上传到演示知识库。
