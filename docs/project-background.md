# AI Agent Workbench 项目背景说明

## 1. 项目背景

团队内部日常协作中存在大量低频但重复的操作：查看日程后评估工时、提交工时记录、查询内部制度、发起资源或系统权限申请、整理审批材料等。这些事情单独看都不复杂，但入口分散、规则隐含、表单繁琐，导致新人或跨团队协作者经常需要反复询问。

传统做法通常有两类：

1. 为每个系统单独写脚本或 CLI 工具。
2. 把制度和流程写成文档，让成员自行查询。

这两类方式都缺少统一交互入口，也难以让 AI 在可控边界内辅助完成任务。直接把内部系统权限交给通用大模型也不可取，因为模型可能误调用工具、拼错命令、越权操作或在没有确认的情况下执行敏感动作。

因此，本项目希望构建一个轻量的 AI 工作台：把团队内已有或模拟的 CLI 工具、MCP 工具、制度知识和操作说明接入到统一的 Web 对话系统中，并通过业务 Agent 的方式组织能力。

## 2. 项目一句话介绍

AI Agent Workbench 是一个基于 Claude Agent SDK 的团队内部 AI 工作台，支持通过配置快速创建业务 Agent，并在 Web 对话系统中安全、可控、可审计地调用 CLI 工具、MCP 工具和 Skills。

## 3. 为什么使用 Claude Agent SDK

本项目不希望实习生从零实现 Agent Loop。通用 Agent 的难点包括上下文管理、工具调用循环、工具结果反馈、多轮状态、MCP 接入和权限控制。如果这些能力都自行实现，8 周兼职实习很容易失控。

Claude Agent SDK 已经提供了通用 Agent 底座能力。本项目使用它承接底层能力，实习生重点关注更贴近真实工程的问题：

1. 如何把业务 Agent 配置化。
2. 如何把 CLI 工具封装成受控工具，而不是让模型自由执行 shell。
3. 如何把 MCP 工具接入 Web 对话系统。
4. 如何为敏感动作增加人工确认。
5. 如何记录工具调用和执行日志，方便复盘与审计。
6. 如何把系统做成可演示、可扩展的内部原型。

## 4. 目标用户与业务场景

目标用户是团队内部成员。系统计划先覆盖内部协作类场景，不覆盖面向外部客户的业务系统。

典型场景：

1. 工时助理 Agent  
用户询问“我这周根据日程大概要填多少工时”，Agent 查询模拟日程和工时规则，生成工时草稿。用户确认后，Agent 调用受控 CLI 提交模拟工时。

2. 制度信息 QA Agent  
用户询问“申请 GPU 机器需要满足什么条件”，Agent 基于内部制度说明和 MCP 工具查询相关条款，给出答案和来源。

3. 权限申请辅助 Agent  
用户说明需要访问某个系统，Agent 帮助收集申请理由、使用期限、资源范围等信息，并生成申请草稿。真实审批不在本项目范围内。

## 5. 项目完成后需要讲清楚的项目故事

以下内容是项目完成后的表达框架，其中描述的能力均为待实现和待验收目标。面试或复盘时，可以按以下逻辑讲述：

1. 问题是什么  
团队内部有很多分散在 CLI、系统页面和文档里的协作流程。成员希望通过自然语言完成这些流程，但直接让大模型操作内部系统存在安全风险。

2. 项目要完成什么  
基于 Claude Agent SDK 实现一个 AI 工作台原型，让用户可以在 Web 页面选择不同业务 Agent，并通过配置文件声明每个 Agent 的系统提示词、工具、Skills 和权限策略。

3. 计划如何实现  
后端需要封装 Claude Agent SDK，前端通过流式对话接口展示回复。CLI 工具需要通过白名单 action 和参数 schema 包装，MCP 工具通过 Agent 配置接入。敏感操作需要进入人工确认流程，工具调用需要写入审计日志。

4. 预期结果是什么  
项目验收时，系统需要能够演示“选择 Agent -> 对话 -> 调用工具 -> 人工确认 -> 执行动作 -> 返回结果 -> 记录日志”的完整闭环。相比单个脚本或单个聊天机器人，它更强调可配置、可控和可扩展。

5. 项目边界是什么  
即使达到本项目的验收标准，交付结果仍是实习原型，而不是生产平台。若要真实上线，还需要接入企业 SSO、真实权限系统、审计存储、部署隔离、真实内部系统 API，并经过更严格的安全评审。

## 6. 项目定位

本项目定位为实习阶段可交付的内部工具原型。

应该做到：

1. 主流程能跑通。
2. 架构边界清楚。
3. 工具调用可控。
4. 演示故事完整。
5. 后续扩展路径明确。

不应该做到：

1. 做成完整商业化 Agent 平台。
2. 接入真实生产系统并执行真实变更。
3. 追求复杂权限、多租户、插件市场和企业级运维。
4. 自己重新实现 LangGraph 级别的 Agent Runtime。
