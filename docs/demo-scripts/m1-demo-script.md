# M1 演示脚本

本脚本用于验收 `timesheet_assistant` 工时助理、SSE 流式回复和同一会话连续追问。

## 演示前准备

1. 按根目录 `README.md` 启动后端和前端。
2. 打开 `http://localhost:5173`。
3. 确认 Agent 下拉框显示“工时助理”。
4. 打开浏览器开发者工具的 Network 面板，便于观察 `messages/stream` 请求。

## 样例一：会议工时草稿

输入：

```text
我今天参加了三个会议，每个会议一小时，请帮我生成工时草稿。
```

预期：

- 页面先显示用户消息和“正在回复”。
- 回复文字逐步出现。
- Agent 整理出约 3 小时会议工时，而不是执行无关任务。

## 样例二：同一会话连续追问

不要刷新页面，继续输入：

```text
再加上两小时需求分析，并汇总今天的总工时。
```

预期：

- 前端继续使用同一个 `conversation_id`。
- Agent 能结合上一条消息中的 3 小时会议工时。
- 汇总结果应为约 5 小时。

这一条用于验证“多轮会话”，不是三个完全独立请求。

## 样例三：结构化周报

输入：

```text
请把今天的工时整理成包含事项、时长和备注的清单，并给出一句工作总结。
```

预期：

- Agent 继续使用当前上下文。
- 回复包含清晰的事项和时长。
- Network 面板中的流式接口返回多个 `delta` 事件，最后返回 `done` 事件。
