# 里程碑 4：项目复盘与模拟面试

## 周期与验收要求

- 周期：第七周到第八周。
- 验收要求：建议在第八周结束前完成最终里程碑验收。
- 验收方式：项目复盘汇报 + Demo 演示 + 模拟面试。

## 阶段目标

本阶段不再新增大功能，重点是查漏补缺、沉淀项目材料、训练项目表达和模拟面试。

本阶段应在 M1-M3 按各自验收标准完成后开始。M4 的目标是让实习生能把项目讲清楚：为什么做、怎么做、为什么这样选型、边界在哪里、有哪些安全风险、后续如何演进。

## 设计思路

项目复盘应围绕“业务背景 -> 技术方案 -> 核心流程 -> 风险控制 -> 项目结果 -> 后续优化”展开。

不建议在 M4 继续堆功能。若 M1-M3 存在影响演示的阻塞问题，可以修复；若只是锦上添花的功能，应记录为后续计划。

## 模块与目的

1. 查漏补缺模块  
目的：修复影响 Demo 的关键问题，确保演示稳定。

2. 项目复盘模块  
目的：沉淀架构图、模块说明、关键技术决策和取舍。

3. 简历包装模块  
目的：将项目经历整理成简历和面试可表达的内容。

4. 模拟面试模块  
目的：检验实习生是否真正理解项目，而不是只会跑 Demo。

## 交付物

1. 项目复盘报告。
2. 系统架构图。
3. Agent manifest 设计说明。
4. 工具调用与权限控制说明。
5. Demo 演示脚本。
6. 简历项目描述。
7. 模拟面试题库与回答要点。
8. 遗留问题清单和后续优化计划。
9. 最终验收记录。

## 任务拆解

1. 查漏补缺
   - 汇总 M1-M3 遗留问题。
   - 按 P0/P1/P2 标注优先级。
   - 只修复影响主流程演示的问题。
   - 记录未修复问题的原因。

2. 项目复盘
   - 梳理项目背景和目标。
   - 绘制系统架构图。
   - 说明 Web、Runtime、Registry、Tool Adapter、Approval、Audit Log 的职责。
   - 总结 Claude Agent SDK 带来的收益和限制。
   - 总结 CLI/MCP/Skills 接入方式。

3. 简历描述
   - 提炼项目名称、技术栈、职责和结果。
   - 准备 3-5 条简历 bullet。
   - 准备 30 秒、2 分钟、5 分钟三个版本的项目介绍。

4. 模拟面试
   - 至少完成 2 轮模拟面试。
   - 每轮记录不会回答或回答不清楚的问题。
   - 根据反馈更新复盘文档和回答要点。

## 模拟面试重点问题

1. 为什么选择 Claude Agent SDK，而不是自己用 LangGraph 实现 Agent Loop？
2. Claude Agent SDK 在这个项目里负责什么？你自己的代码负责什么？
3. Agent manifest 的核心字段有哪些？如何新增一个 Agent？
4. 为什么不能把 shell 直接暴露给模型？
5. CLI 工具如何防止命令注入？
6. 什么动作需要人工确认？为什么？
7. MCP 工具和 CLI 工具在系统里有什么区别？
8. Skills 在项目里解决什么问题？
9. 审计日志记录哪些字段？出现问题时如何排查？
10. 如果要上线到团队内部，还缺哪些能力？
11. 如果一个 MCP server 启动失败，系统应该如何降级？
12. 如何保证不同 Agent 的上下文和工具权限不串？

## 验收标准

1. 实习生能独立完成 10 分钟项目讲解。
2. 实习生能稳定演示 M3 全流程。
3. 实习生能解释系统架构和关键模块职责。
4. 实习生能解释技术选型和边界控制。
5. 实习生能回答工具安全、人工确认和审计相关问题。
6. 复盘文档和简历描述可直接用于后续面试准备。

## 明确不做

1. 不在 M4 新增第三个完整 Agent。
2. 不接真实内部系统。
3. 不做生产级部署。
4. 不重构整个工程结构。
5. 不为了展示效果牺牲安全边界。
