# 工作台前端设计调整

更新日期：2026-10-19

## 参考与取舍

| 官方参考 | 参考的设计方式 | 本工作台的实现 |
| --- | --- | --- |
| [Open WebUI 界面整理](https://www.openwebui.com/blog/v0-11-0-the-interface-reorganized) | 侧栏按功能分组、减轻聊天区视觉干扰 | 把 Agent 与历史会话移到侧栏，保留主区域用于阅读和输入 |
| [LibreChat Agents](https://www.librechat.ai/docs/features/agents) | Agent 配置入口、新对话示例问题 | 侧栏创建 Agent；按当前 Agent 提供可编辑的示例问题 |

界面采用浅色侧栏、白色聊天区和紫色操作强调。只显示现有功能；工作区名称不代表已实现账号或用户隔离。

## 操作方式

- 左侧包含新建对话、知识库、Agent 列表和当前 Agent 的会话历史；搜索仅筛选该 Agent 的已有会话标题与标签。
- 顶栏保留绑定知识库入口，桌面可以收起侧栏；窄屏使用导航抽屉，也可以在顶栏切换 Agent。
- 新对话展示 Agent 用途和三个示例问题。点击示例只填入输入框，需要用户手动发送。
- 输入框自动增高，Enter 发送、Shift + Enter 换行；中文输入法选词时不触发发送。
- 助理回答使用较宽的阅读列；用户消息使用浅紫色气泡。引用来源与 Markdown 原文预览沿用已有流程。
- 抽屉打开时背景内容不可交互，支持 Escape 关闭和恢复焦点；按钮提供键盘焦点标识和可访问名称。

## 本次验证

- 前端 40 项自动化测试通过，TypeScript 与生产构建通过。
- 浏览器检查了 1280px 桌面布局、320px 窄屏布局与默认浏览器尺寸。
- 实际检查 Agent 切换、会话搜索（含无匹配）、历史加载、新建对话、示例填入、多行输入、抽屉开关与 Escape 关闭。
- 实际打开知识库管理、创建 Agent、知识库绑定，以及历史消息的 Markdown 原文预览；没有保存新的 Agent 或修改知识库绑定。
- 本次未发送新消息调用外部模型，未重跑后端回归；后端行为没有修改。
