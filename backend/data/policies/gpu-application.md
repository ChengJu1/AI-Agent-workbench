# GPU资源申请管理制度
- 制度ID: GPU-001
- 生效日期: 2024-06-01
- 适用对象: 开发团队
- 关键词: GPU、显卡、算力、模型训练、资源申请

## 审核规则
- 部门主管负责审核项目的业务必要性，确认申请是否符合制度要求。
- IT资源管理部门负责检查GPU型号、数量和可用时间是否能够满足申请。
- 业务审核和资源审核都通过后才能批准申请。材料不完整时退回补充；不符合申请条件时拒绝申请并告知原因。

## GPU申请条件
1. 申请人必须是公司正式员工，且在开发团队中有明确的项目需求。
2. 申请人需提供详细的项目计划，包括项目目标、所需GPU资源类型及数量、预计使用时间和使用频率。
3. 申请必须得到直属部门主管批准。

## 申请流程
1. 提交申请：申请人需填写《GPU资源申请表》，并附上项目计划书，提交至部门主管审核。
2. 业务审核：部门主管审核申请表和项目计划书。材料不完整时退回补充；不符合申请条件时拒绝申请并告知原因。
3. 批准与分配：审核通过后，部门主管将申请表提交至IT资源管理部门，由IT部门根据资源情况进行GPU资源的分配。
4. 使用与管理：申请人获得GPU资源后，需按照项目计划合理使用，并定期向部门主管汇报使用情况。

## 使用限制
1. GPU资源仅限于公司内部项目使用，禁止用于个人或非公司相关的研究和开发。
2. 申请人需遵守公司相关的安全和数据保护政策，确保GPU资源的使用不涉及任何违法或不当行为。
3. GPU资源的使用时间和频率应根据项目需求合理安排，避免资源浪费。

## 无法满足条件时的处理
- 材料不完整：应该补充材料后重新申请。
- 特殊需求或制度无法判断：应该联系IT资源管理部门进行人工确认。
