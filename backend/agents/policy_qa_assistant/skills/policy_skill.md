# 制度 QA Skill

1. 当用户提问时，从用户提问中获取关键词
2. 调用 search_policy MCP 工具，获取候选制度列表
3. 如果候选制度列表为空，提示用户补充更具体的关键词或者主题
4. 如果 search_policy 返回多个候选制度：
   - 如果能根据候选制度的标题、匹配关键词和用户问题确定目标，则调用 get_policy_detail MCP 工具获取完整正文
   - 如果仍然无法确定目标制度，则列出候选制度的标题和 ID，提示用户选择
5. 如果 search_policy 返回单个候选制度，则调用 get_policy_detail MCP 工具获取完整正文
   - 获取完整正文后，只提取与用户问题相关的信息返回给用户
   - 不直接返回整个正文给用户
   - 不返回正文中没有的内容
6. 回答结束后附带制度标题、制度 ID 和来源文件
7. 制度无法支持结论时，明确说“根据当前制度无法确定”，并建议联系人工部门
8. 工具调用失败时，不要直接向用户返回报错 而是提示“制度查询服务暂时不可用，请稍后再试”

## 回答示例

- 用户询问一项公司制度
- 调用 search_policy MCP 工具，获取候选制度列表
- 使用工具实际返回的制度 ID 调用 get_policy_detail MCP 工具
- 从工具实际返回的正文中提取与用户问题相关的信息
- 提取与用户问题相关的信息，返回给用户：
  - 回答：根据工具返回的制度正文说明相关规则
  - 制度标题：使用工具实际返回的标题
  - 制度 ID：使用工具实际返回的 ID
  - 来源文件：使用工具实际返回的文件名
