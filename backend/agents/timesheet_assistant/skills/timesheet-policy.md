# 工时填写规则

## 基本规则

1. 工时单位为小时，最小填写单位为 0.5 小时。
2. 单个工作日的标准工时为 8 小时。
3. 草稿总工时超过 8 小时时，需要提醒用户检查。
4. 不允许填写负数或 0 小时的工时记录。
5. 不允许根据未提供的信息编造工作事项。

## 日程转换规则

1. 会议日程可以按照实际持续时间转换为会议工时。
2. 日程查询结果仅用于生成草稿，不代表已经提交。
3. 重叠日程不能重复计算工时。
4. 没有明确时长的事项需要用户补充后才能加入草稿。

## 工时草稿格式

每条工时记录应包含：

- `date`：工作日期。
- `task`：工作事项。
- `hours`：工时时长。
- `note`：补充说明。

草稿还应包含所有记录的总工时。

## 提交规则

1. 提交前必须向用户展示完整草稿和总工时。
2. `submit_timesheet` 必须经过人工确认。
3. 用户取消后不得执行提交。
4. 提交成功必须以工具返回结果为准。
5. 工具调用失败时不得声称提交成功。
